# Edge site members

**Members** grants people access to **this Edge site** with a site-scoped role. Org owners and admins already have full access and do not need to be listed here.

## Roles

Typical options mirror site membership elsewhere in dply (e.g. manage vs deploy-oriented access). Only users who can **manage members** on the site can add or remove rows.

## How to use it

1. Pick an org user who is not already a site member.
2. Choose a **role**.
3. **Add** — they can open this site’s workspace according to that role.

Remove a member when they no longer need site access; org-level roles are unchanged.

## Tips

- Prefer site members over sharing org-admin for contractors who only touch one Edge app.
- Deploy-only roles cannot change notification subscriptions or destructive settings.
